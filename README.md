# Overview

Healthcare Fraud Detection System is an enterprise AI platform that detects fraudulent healthcare insurance claims before approval. The system combines Machine Learning, FastAPI, Azure SQL, and Apache Spark to deliver real-time fraud detection and interactive analytics dashboards.

---

# Project Highlights

| Feature | Description |
|---------|-------------|

| Backend | FastAPI REST APIs |
| Frontend | React + Vite |
| Database | Azure SQL |
